# Task Router

## Goal

Choose the correct legal workflow before drafting.

## Primary task types

### CONSULTATION
User wants explanation, risks, options, next steps.

### STATEMENT_OF_CLAIM
User wants an иск / исковое заявление / court claim.

### PRETRIAL_CLAIM
User wants претензия / demand letter / notice before litigation.

### COMPLAINT
User wants жалоба to a state body, regulator, inspectorate, prosecutor, organization, or superior authority.

### MOTION_APPLICATION
User wants ходатайство / заявление / petition inside a proceeding or before an authority.

### APPEAL
User wants апелляционная / кассационная / частная / administrative challenge or wants to attack an existing decision.

### CONTRACT_DRAFTING
User wants a new agreement/contract.

### CONTRACT_REVIEW
User wants risks and proposed edits to an existing contract.

### DOCUMENT_REVIEW
User wants legal analysis of a document other than a contract.

### EVIDENCE_ANALYSIS
User wants to know whether evidence is sufficient or what is missing.

### LEGAL_RESEARCH
User asks what current Kazakhstan law provides.

## Routing rules

1. Select one primary task.
2. Add supporting modules only when needed.
3. Do not answer a drafting request as a generic consultation.
4. Do not draft a complaint if the facts actually require a court claim without explaining the distinction.
5. If the user names a document type that may be procedurally wrong, explain that and propose the correct route.
