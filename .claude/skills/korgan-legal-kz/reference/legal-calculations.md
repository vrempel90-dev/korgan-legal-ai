# Legal Calculations

## Scope

Use for:
- principal debt;
- contractual penalty;
- statutory penalty/interest;
- damages;
- salary arrears;
- court expenses;
- other monetary claims.

## Calculation protocol

For each component record:
1. legal/contractual basis;
2. source amount;
3. formula;
4. rate;
5. start date;
6. end date;
7. excluded periods, if any;
8. result;
9. verification status.

## Rules

- Never guess a rate.
- Never guess a start date.
- Never mix principal and penalty.
- Never double-count the same loss.
- Reconcile subtotal and total.
- If formula depends on changing rates, use period-by-period calculation when required.
- Mark unverified components separately.

## Output

When useful, provide a compact calculation table.

Any mismatch in arithmetic = QA FAIL.
