# Appeals / Challenges

## Goal

Attack an existing judgment, ruling, administrative act or decision with issue-specific reasoning, not a generic disagreement.

## Mandatory inputs

Need:
- challenged decision;
- issuing body/court;
- date;
- date received/served if deadline depends on it;
- procedural status;
- what outcome the user wants;
- record/evidence;
- prior submissions;
- exact appellate route.

If the decision itself is unavailable, the draft is preliminary.

## Analysis framework

For each ground:

1. What did the decision conclude?
2. What fact/law/procedure is challenged?
3. What source/evidence contradicts it?
4. Why the error is material?
5. What appellate remedy follows?

## Ground categories

Use only when supported:
- incorrect application/interpretation of law;
- incomplete fact finding;
- findings inconsistent with evidence;
- procedural violation affecting outcome;
- refusal/failure to assess evidence;
- jurisdiction/competence error;
- disproportionality or reasoning defect where legally relevant.

## Structure

1. Appellate body/court
2. Parties/case
3. Challenged decision
4. Short procedural history
5. Grounds, numbered
6. Evidence/source references
7. Requested appellate relief
8. Attachments

## Deadline gate

Never state an appeal deadline from memory.
Verify official current law and service/receipt facts.
